## Process

CTIN 488 final project with a three-week schedule and one-week iteration cadence.

**Week 1 — Brainstorm.** We wanted a quick, fun game like Spoons, chose a chef theme, and added a bell for table presence. First prototype used index cards.

**Week 2 — Readability.** Playtests showed index cards were hard to parse at speed; we redesigned in Canva for fast recognition while passing cards.

**Week 3 — Rules and polish.** We moved rules from text-heavy docs to diagram-first layouts, adjusted rules that let one playstyle shut others out, and submitted for a near-perfect score.
