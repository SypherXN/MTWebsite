## Duties

- Learn about developing with Unity and C#
- Develop a 3D roguelike spaceship first-person shooter game
- Work alongside fellow students to get playtest feedback
- Identify and debug problems based on playtest feedback
- Promote UCSB's game development program at the Gaucho Game Lab showcase

## Gallery

Gameplay and showcase footage appear in the hero video.

## Process

This was an early Unity project built over a single academic quarter: iterate on roguelike progression (scrap and upgrades), tune combat feel in FPS ship controls, and use weekly playtests with peers to find and fix friction before the Gaucho Game Lab showcase.
