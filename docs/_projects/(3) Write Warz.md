## Duties

During my internship at Boltz Entertainment, I focused primarily on the technical side of game development while also contributing to game design discussions. I had the opportunity to work across multiple areas of the project—from implementing new game modes to developing an emote system. I learned to quickly integrate into an existing codebase by thoroughly reading through it and seeking guidance from full-time developers when needed. I also collaborated closely with other departments—including art, visual effects, sound, and the studio director—to help deliver the best possible experience for players.

- Implemented a custom emote system from the ground up to enhance player-to-player interaction
- Leveraged Unity's Remote Procedure Call (RPC) system to ensure a seamless multiplayer experience for players
- Optimized game asset usage and build process, reducing total game size by over 60%
- Redesigned character abilities to introduce deeper strategic gameplay
