# Neuromancer

### Role

Enemy AI Lead Developer and Game Designer

### Dates

January 2023 - September 2023

### Genre

Adventure, Action, Puzzle, Strategy

### Platform

PC

### Description

Neuromancer is an action-adventure game where the player uses the power of Neuromancy to control the minds of enemies. The player themselves are quite weak and cannot do much themselves. Instead they must utilize the enemies to fight enemies/bosses and solve puzzles.

## Duties

- Cooperate with 9 other students to produce a game designed around a mind control mechanic
- Lead development on enemy and ally units AI that controls them
- Utilize GitHub for version control to streamline code organization
- Synchronize with other team members during daily Scrum meetings
- Develop a way to convert enemy units into ally units
- Create a unit skill system to allow unique combat and puzzles
